About this project

apis.sendafun.com is an open-source index of free public APIs for developers — search, filter, health-check, online playground and multi-language code generation.

Dataset source: public-apis (MIT License), auto-synced daily via GitHub Actions; you are welcome to contribute new APIs via “Submit API”.

License: this project is MIT; the API dataset follows the MIT License of public-apis.
