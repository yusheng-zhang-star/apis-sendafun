关于本项目

apis.sendafun.com 是一个开源的免费公共 API 索引平台，面向开发者提供搜索、筛选、健康检测、在线 Playground 调试与多语言代码生成能力。

数据集来源：public-apis（MIT License），通过 GitHub Actions 每日自动同步；同时欢迎开发者通过“提交 API”贡献新接口。
